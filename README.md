# mostra - Punto de venta

Instaladores oficiales para Windows x64 de mostra, por AP Code.

Descarga el instalador en [Releases](https://github.com/pedroxd12/mostra-releases/releases/latest).

El mismo instalador sirve para todos los negocios. En la primera instalación indica la dirección HTTPS de su servidor. Las actualizaciones conservan esa configuración y los datos locales de la terminal.

La aplicación consulta este canal al abrir, cada seis horas y desde Ajustes > Acerca de > Buscar actualizaciones. La instalación se confirma dentro de la aplicación.

Este repositorio distribuye binarios; el código del producto se mantiene en su repositorio de desarrollo.
